## 📋 项目简介

- 本人负责计算机协会管理系统的后端服务，提供用户注册、登录、JWT 令牌认证、密码找回等功能。

### 主要功能

-  **用户注册** - 支持用户名、邮箱注册，自动验证唯一性
-  **用户登录** - 支持用户名或邮箱登录，生成 JWT 令牌
-  **密码加密** - 使用 BCrypt 算法进行密码加密存储
-  **JWT 认证** - 基于 JWT 的无状态认证机制
-  **密码找回** - 通过邮箱验证码重置密码
-  **Redis 缓存** - 验证码存储与过期管理
-  **邮件服务** - 支持 SMTP 邮件发送
-  **统一响应** - 标准化的 API 响应格式
-  **异常处理** - 全局异常捕获与友好提示
-  **API 文档** - 集成 Swagger/OpenAPI 文档

## 安全设计

### 密码加密
- 使用 **BCrypt** 算法进行密码加密
- 密码强度要求：至少 6 位字符

### JWT 认证
- **算法**: HS512
- **有效期**: 24 小时 (可配置)
- **载荷**: 包含用户名和创建时间

### Spring Security 配置
- 禁用 CSRF 保护 (适用于无状态 API)
- 允许匿名访问注册、登录、密码重置接口
- 其他接口需要认证
